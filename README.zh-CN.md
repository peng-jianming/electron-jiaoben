# TaskLineMachine 任务状态机逻辑

## 核心机制

### 1. 界面注册
- 使用 `@state(Field)` 装饰器注册需要处理的界面
- 每个界面包含：
  - **Field配置**：定义如何识别该界面（字库找图或YOLO检测）
  - **处理函数**：识别到该界面后执行的逻辑

### 2. 状态机运行流程

#### 主循环（`start()` 方法）
1. **持续截图**：不断调用 `controller.截图()` 获取当前屏幕
2. **遍历已注册界面**：按顺序检查每个已注册的界面是否匹配
3. **识别成功**：
   - 执行对应界面的处理函数
   - 更新当前界面状态
   - 重置未知界面计时器
   - 处理函数可以返回字典更新上下文，或返回 `False` 表示处理失败
4. **识别失败（未知界面）**：
   - 记录进入未知界面的时间
   - 启动60秒超时计时器
   - **TODO**: 遍历所有未注册的界面，尝试找到并关闭（功能待实现）
   - 如果60秒内仍未识别到已注册界面：
     - 保存截图到 `resource/unknown/` 目录
     - 播放提示音乐（`resource/music.mp3`）
     - 重置计时器，继续监控

### 3. 上下文管理
- 使用 `_context` 字典存储任务执行过程中的上下文信息
- 处理函数可以通过返回字典来更新上下文
- 支持通过 `update_context()` 方法手动更新上下文
- 自动记录 `上一状态` 信息

### 4. 界面识别方式
- **字库找图**：使用 `opencv字库找图()` 方法，支持颜色偏色匹配
- **YOLO检测**：使用 `yolo()` 方法进行目标检测

### 5. 状态机控制
- `start()`: 启动状态机，进入主循环
- `stop()`: 停止状态机，设置 `_is_running = False`
- 异常处理：运行异常时自动停止状态机

## 使用示例

```python
machine = TaskLineMachine(device_id)

@machine.state(Field配置)
def 处理函数(context):
    # 处理逻辑
    # 可以返回字典更新上下文
    # 可以返回 False 表示处理失败
    return {"key": "value"}

machine.start()  # 启动状态机
```
