# ConfigTab 组件功能详细总结

## 1. 组件定位与核心职责

`ConfigTab.vue` 是图片处理器中的“配置中心”组件，承担以下核心职责：

1. **配置文件管理**
   - 选择/加载/打开 JSON 配置文件。
   - 自动保存配置变更（`watch(data, { deep: true })` 后写回文件）。
   - 持久化配置文件路径到本地路径配置（`savePaths/getPaths`）。

2. **配置结构化编辑**
   - 以“界面 -> 元素 -> 子配置”的方式可视化编辑配置。
   - 支持界面级、元素级的参数编辑（类型、相似度、查找区域、误触区域、固定点击区域等）。
   - 支持新增/删除界面、元素、滑动区域、识字区域。

3. **资源（点阵/图片）生产与绑定**
   - 从当前截图和圈选区域生成点阵（含偏色、自动裁剪、偏移点击区域）。
   - 将圈选区域图片直接加入图片库（包含标准命名规则）。
   - 配置项通过命名规则与点阵库/图片库中的资源进行“弱耦合绑定”。

4. **联动测试与联动清理**
   - 从配置项直接触发测试（点阵测试 / 图片模板匹配测试）。
   - 删除配置节点时，支持级联清理关联的点阵库/图片库资源。

## 2. UI 区域与交互模块

### 2.1 顶部文件区
- 选择配置：调用 Electron IPC 选择并读取 JSON 文件。
- 打开配置：调用系统打开文件。
- 路径持久化：配置路径写入本地路径表，启动自动回填。

### 2.2 左侧“界面列表”
- 展示配置顶层 key（界面名）。
- 每个界面支持缩略图显示（从图片库中查找 `缩略图_界面名`）。
- 展示该界面的元素数量统计。
- 可新建界面，初始化标准字段结构（`类型/查找区域/相似度/元素/滑动区域/识字区域/误触区域`）。

### 2.3 右侧结构化编辑区
- **基础信息卡片**：界面级相似度、查找区域、误触区域、测试、删除。
- **特征列表卡片**：根据当前类型自动展示关联点阵或图片特征缩略图，支持测试/删除。
- **滑动区域列表**：编辑“起始区域/结束区域”。
- **识字区域列表**：字符串型区域可直接编辑；对象型提示导出 JSON 编辑。
- **元素列表**：每个元素支持类型相关字段编辑、测试、删除，以及各自特征列表管理。

### 2.4 测试弹层
- 点阵类型：打开 `FontLibraryMatchDebug`，并传入初始名称/相似度/区域。
- 图片/彩图类型：通过事件通知父组件打开图片测试（`ImageLibraryTab` 提供测试能力）。

### 2.5 添加配置抽屉（制作点阵/添加图片）
- 按配置类型切换模式：
  - `点阵` -> 字库制作模式：选色、偏色、二值化预览、自动裁剪、偏移点击区域。
  - `图片/彩图` -> 图片添加模式：将当前圈选图加入图片库。
- 支持偏移点击区域圈选（相对主圈选区域计算偏移值）。

## 3. 配置数据模型与关键规则

### 3.1 类型归一化
- `normalizeConfigType` 会将历史/别名类型统一到：`固定区域 | 点阵 | 图片 | 彩图`。
- `字库` 会被映射成 `点阵`，固定区域相关旧文案也会被归一化。

### 3.2 特征模式映射
- `点阵` -> 使用点阵库（font mode）。
- `图片`/`彩图` -> 使用图片库（image mode）。
- `固定区域` -> 无特征列表。

### 3.3 命名驱动的资源关联
- 界面级基名：`界面名`
- 元素级基名：`界面名_元素名`
- 可匹配命名：`基名`、`基名_数字`、`基名_数字_偏移区域`、兼容 `基名_偏移区域`。
- 这套规则用于展示、测试定位、删除级联。

## 4. 与点阵库 `FontLibraryTab.vue` 的关系

### 4.1 数据关系
- `ConfigTab` 通过 `props.fontLibraryList` 获取点阵库列表。
- 点阵预览通过 `fontMatrixRowToDataUrl` 动态生成缩略图。

### 4.2 资源新增链路
1. 在 `ConfigTab` 抽屉中完成选色/偏色/二值化。
2. 生成 `fontItem`（matrix、宽高、偏色、偏移点击区域、name 等）。
3. 触发 `emit("add-font-library", fontItem, resolve)`。
4. 父组件转调 `FontLibraryTab` 的 `addFontLibraryItem` 写入字库文件并刷新列表。

### 4.3 测试链路
- 点阵测试由 `ConfigTab` 内置 `FontLibraryMatchDebug` 完成。
- 初始参数由当前配置节点提供（名称、相似度、查找区域）。

### 4.4 删除联动
- 单删和级联删除都通过 `delete-library-resource` 事件下发。
- 父组件可调用 `FontLibraryTab` 暴露的 `deleteById/deleteByExactName/deleteByName` 完成真实删除。

## 5. 与图片库 `ImageLibraryTab.vue` 的关系

### 5.1 数据关系
- `ConfigTab` 通过 `props.imageLibraryList` 获取图片库列表。
- 用于特征预览与界面缩略图映射（`缩略图_界面名`）。

### 5.2 图片新增链路
1. 在 `图片/彩图` 类型配置中打开图片抽屉。
2. 取当前图和圈选区域生成预览。
3. `emit("add-image-to-library", { name, selectionRect, currentImageUrl })`。
4. 父组件转调 `ImageLibraryTab.addImageItemFromConfig` 加入列表并同步 `.npz`。

### 5.3 图片测试链路
- `ConfigTab` 发出 `open-image-test` 事件，不直接做匹配。
- `matchMode`：`图片=gray`，`彩图=color`。
- 父组件转调 `ImageLibraryTab.openTestByImageName` 打开模板匹配弹窗。

### 5.4 删除联动
- `ConfigTab` 统一输出删除 payload（`图片/彩图`）。
- 父组件调用 `ImageLibraryTab.deleteById/deleteByExactName/deleteByName` 执行删除与同步。

## 6. 中枢定位（配置与资源协同）

`ConfigTab` 是“配置编辑 + 资源编排”中枢：
- 向下读取两库列表（props）做预览和匹配。
- 向上通过事件让父组件分发到对应库执行写入、删除、测试。
- 删除配置时做命名规则级联清理，降低残留资源风险。

简言之：`ConfigTab` 管“配置语义”，`FontLibraryTab`/`ImageLibraryTab` 管“资源实体与能力执行”。

## 7. 关键事件契约

- `add-font-library(fontItem, resolve)`：新增点阵资源。
- `add-image-to-library(payload)`：新增图片资源。
- `delete-library-resource(payload)`：删除单条或批量关联资源。
- `open-image-test(payload)`：打开图片模板匹配测试。
- `start-code-generator-selection` / `stop-code-generator-selection`：控制偏移区域圈选状态。

## 8. 优势与注意点

### 优势
- 配置编辑、资源制作、测试、删除形成完整闭环。
- 结构化编辑体验强，且兼容历史命名/类型。
- 联动删除减少“配置与资源不一致”。

### 注意点
- 资源关联主要靠命名规则，不是 ID 强绑定，命名规范必须一致。
- 深度监听自动保存会持续写盘，大配置文件需关注性能。
- 命名偏离规则时，可能影响特征展示或级联清理准确性。

## 9. 一句话总结

`ConfigTab` 是配置 JSON 的可视化编辑器与资源编排控制台，通过命名规则把配置节点与点阵库、图片库连接起来，实现制作、预览、测试、删除、级联清理的一体化流程。
