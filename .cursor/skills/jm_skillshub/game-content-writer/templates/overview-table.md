# 步骤总览表模板（Overview Table）

> 用于 `03-script` 阶段开头，快速展示整条内容的结构，方便你一眼看懂整条视频/图文的安排。

复制下面这块作为总览表的基础结构，根据实际步骤数量填充：

```markdown
## 步骤总览

| Step | 名称/主题 | 教学目标 | 主要内容概述 |
|------|-----------|----------|--------------|
| 1 | {步骤1名称} | {一句话教学目标} | {1–2 句话概述这一段大致讲什么} |
| 2 | {步骤2名称} | {一句话教学目标} | {……} |
| 3 | {步骤3名称} | {一句话教学目标} | {……} |
| … | … | … | … |
```

> 建议：
> - “名称/主题” 尽量口语、具体，方便你之后给视频分段或写小标题；
> - “教学目标” 保持一句话，像“这一步要帮观众完成什么小任务”；
> - “主要内容概述” 不要塞完整细节，只要给未来的你一个“鸟瞰图”。
