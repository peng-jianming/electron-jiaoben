# 单个步骤脚本块模板（Step Script Block）

> 用于 `03-script` 阶段，为每个步骤生成统一结构的「图文 + 口播 + 画面规划」。

复制下面这块作为单个 Step 的标准输出格式：

```markdown
Step N：{步骤名称}

**教学目标：**
- 用 1 句话说明这个步骤要帮观众解决什么问题

**图文稿内容（适合图文平台）：**
- 用图文阅读视角来写，可以包含：
  - 小标题（可选）
  - 分段正文
  - 列表要点
- 要求：
  - 对新手友好，必要时补上一句“为什么要这样做”
  - 避免长篇大段不分段

**口播稿内容（适合直接照读/略改）：**
- 用自然口语写台词，每一句尽量不要太长，便于配音/录制：
  - 可以使用连接词：“首先”、“然后”、“简单讲就是……”
  - 不要强行堆叠网络梗，除非风格模板要求
- 建议每一两句换一行，方便后期剪辑对齐音频：
  - 例：
    - “首先，我们先看一下这套配装的大致思路。”
    - “这套是给新手准备的，你只要日常肯刷，就能慢慢成型。”

**画面/素材指示（关键）：**
- 需要的素材类型：
  - 例：一张角色属性面板截图（包含攻击力、暴击、爆伤）
  - 例：一段约 5–8 秒的实战录屏，展示完整连招
  - 例：一张‘错误配装 vs 推荐配装’的对比图
- 出现时机：
  - 例：“本步骤开始时，先给 1 秒角色立绘，然后切到属性面板。”
  - 例：“当台词说到‘三件核心装备’这句话时，切入三件装备的对比图。”
- 结束/切换时机：
  - 例：“讲完这三条要点之后，画面切回实战录屏。”
  - 例：“本步骤结束前，停留在配装面板大约 1 秒，再淡出到下一步。”
- 画面构图提示（可选）：
  - 是否需要圈重点、用箭头强调、打马赛克、放大某个区域等

**补充备注（给未来自己看的可选说明）：**
- 例：“如果实战录屏时间不够，可以只截取最后一段爆发伤害。”
- 例：“这一段对新手略难，可以考虑放慢语速或多停留 1–2 秒。”
```
