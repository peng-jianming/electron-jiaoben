# 风格模板说明示例（Style Spec Example）

> 说明：  
> - 真正的“风格模板”由你自己维护，本文件只是一个写法示例；  
> - 你可以为不同的博主风格 / 账号定位，写多份类似的 spec，在调用时用 `style_id` + `style_spec` 指定。

下面是一个偏“硬核攻略向”的示例，你可以按需复制修改：

```yaml
style_id: hardcore_guide_v1
style_spec: |
  - 整体语气偏冷静、理性，不靠情绪起伏撑内容。
  - 优先讲清原理和结论，不讲八卦。
  - 开头习惯先给结论：“值/不值”、“适合谁”、“这一期会讲什么”。
  - 句式偏短，少用网络梗，拒绝堆叠口头禅。
  - 段落结构倾向：先结论 → 再给 2–3 个关键理由 → 简短总结。
  - 标题/小标题里可以适度用数字，比如“3 个要点”、“2 种方案”。
  - 不做夸张标题党，但允许轻微“强化痛点/收益”的表述。
```

你也可以为其它风格写 spec，例如“轻松吐槽向”“兄弟聊天风”“版本点评杂谈风”等，只要保持结构清楚，方便在 SKILL 调用时粘贴即可。
